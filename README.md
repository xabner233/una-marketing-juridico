# Portfólio de sites · LR Social Media

Cada pasta é um site, publicado automaticamente em `lrsocialmedia.com.br/portfolio/<pasta>` a cada alteração na branch `main`.
As cópias têm `noindex` (não aparecem no Google) e um selo "Projeto LR Social Media" que volta para a página Criação de sites.

| Pasta | Endereço | Site original |
|---|---|---|
| `isabella/` | lrsocialmedia.com.br/portfolio/isabella | psicologaisabellalacerda.com.br |
| `una/` | lrsocialmedia.com.br/portfolio/una | — |
| `renovo/` | lrsocialmedia.com.br/portfolio/renovo | renovoestofados.com.br |
| `renovo-2/` | lrsocialmedia.com.br/portfolio/renovo-2 | — (versão 2.0) |

Site novo: crie uma pasta com o `index.html` dentro e salve. O deploy faz o resto.
