# Portfólio de sites · LR Social Media

Cada pasta é um site, publicado automaticamente em `lrsocialmedia.com.br/portfolio/<pasta>` a cada alteração na branch `main`.
As cópias têm `noindex` (não aparecem no Google) e um selo "Projeto LR Social Media" que volta para a página Criação de sites.
